# Hero Adventure Platformer

**Hero Adventure Platformer** é um jogo de plataforma 2D desenvolvido usando **PgZero** e Python. O jogador controla um herói que deve pular obstáculos, evitar inimigos e coletar moedas para completar o nível.  

---

## 🎮 Como Jogar

- Use as **setas esquerda e direita** para se mover.
- Pressione **SPACE** para pular.
- Colete moedas espalhadas pelo mapa para aumentar sua pontuação.
- Evite os inimigos! Se colidir, você volta ao início do nível.
- O objetivo é chegar ao **final do mapa** (`x > 1900`) para ganhar o jogo.

---

## 🕹️ Controles

| Ação            | Tecla               |
|-----------------|------------------|
| Mover para a direita | **→**            |
| Mover para a esquerda | **←**         |
| Pular           | **SPACE**         |
| Menu - Ativar/Desativar som | Clique no botão SOUND |
| Menu - Iniciar jogo | Clique no botão START GAME |
| Menu - Sair     | Clique no botão EXIT |

---

## ⚡ Requisitos

- Python 3.11 ou superior  
- PgZero (`pip install pgzero`)  

**OBS:** Apenas as bibliotecas **PgZero**, `math` e `random` foram utilizadas. Não é necessário instalar Pygame diretamente.
